# Submitted-paper numerical results

This directory provides machine-readable copies of the numerical values reported in the submitted ICASSP 2027 manuscript.

- `table1_temporal_diagnosis.csv` — temporal diagnosis of forgetting.
- `table2_retention_adaptation.csv` — retention–adaptation results, including cross-backbone evaluation.
- `table3_ablation.csv` — CGMR design ablations on CL-MASR with Whisper-small.
- `fig4_repairability_contrasts.csv` — state-A versus state-D complete-repair-rate contrasts annotated in Fig. 4.

These files are intended as stable result artifacts for checking, plotting, and downstream comparison. The executable validation under `examples/` is a separate compact implementation check.

Experimental settings are documented in `docs/HYPERPARAMETERS.md`, and the manuscript-to-repository mapping is summarized in `docs/PAPER_REPRODUCTION.md`.
